Podmetrix

A local AI that watches your footage so you don't have to.

You record three hours on Monday and edit on Friday, by which point you've forgotten what happened — so you scrub the whole file hunting for moments you personally lived through. That pass scales with how long you recorded, not with the video you ship.

Every tool here picks highlights for you. That's a taste judgement, and when it's wrong you can't tell whether a moment is missing or was thrown away. Podmetrix is a mapper, not a cutter — it never drops a stretch. Boring ones get labelled "walking, nothing happens", so a gap always means nothing was there.

No public dataset exists for "moments a creator would bookmark", so I made one: watched a 30-minute slice, marked all 114 events, then built an LLM-judge pipeline to score against it — with audit sheets, because the judge was wrong often enough that I needed to overrule it.

The jump came from discovering the model wasn't blind, it was under-fed. I'd been tuning prompts. The frame budget was the whole story.

One slice of one video. A prompt sweep across four videos came back insignificant on every arm — committed to the repo, because it's the reason I stopped touching the prompt.

MedicScribe

A medical scribe that speaks Manglish, and keeps nothing.

Every scribe on the market assumes a monolingual English consultation. A Malaysian clinic visit mixes English, Mandarin, Bahasa Melayu and Tamil inside one sentence — "your sugar level, uh, sudah naik, so we adjust the metformin lah". Doctor hits Record; audio goes to a GPU box on the clinic's own network; a structured note comes back in under thirty seconds.

4languages, mid-sentence
0bytes kept afterwards
<30sStop → finished note

The regulation was harder than the accuracy. Under Malaysia's PDPA, a scribe that uploads consultation audio makes the clinic liable for a data flow it can't inspect. So privacy is enforced in code, not a policy PDF: no database, audio unlinked the instant you press Stop, transcript in RAM only, a TTL reaper for crash orphans, and a live /transparency endpoint reporting the real file count so anyone can check from outside.

My favourite decision was a deletion. The obvious build detects language, routes to a model, transcribes, then translates. I collapsed it into one Whisper pass with task: translate. Then I learned Whisper is confidently wrong about language — on a real 22-minute Mandarin consult it picked Malay at p=0.62 and emitted Malay prose for the entire file, silently. More scanning only finds a more confident wrong answer. Under translate that degrades to slightly worse English instead of destroying the note — which is the real reason the design holds, and not why I originally chose it.

Field-tested on real consultations. The clinic pitch was declined on legal and ethics grounds and I agree with it. So: it works, and it is not deployed. Not a medical device, not certified, not fit for clinical use.

The box

4 × RTX 3090 96 GB VRAM NVLink bonded pairs GPU0↔GPU2 · GPU1↔GPU3 56 GB/s per pair serving vLLM · llama.cpp tensor + pipeline parallel egress none

I serve my own models — no inference bill, no data leaving the house. It also means when it breaks it's mine to fix, and most of what I know about systems I learned from this machine misbehaving.

Best example: one card sat at 89°C and thermally throttled while its three siblings were fine. The easy story is "bad card, repaste it". Instead I physically swapped the two identical cards between slots — and the fault stayed with the slot. It was airflow: that card is the upper half of a three-slot NVLink pair, its intake fans choked about a third of a slot above its neighbour's backplate. No repaste would ever have fixed it. Three fan configurations later, all within 2°C, I accepted it was structural.

So I solved it with power instead. Swept caps at 290 / 260 / 230 / 200W under a real workload: 260W is the knee — twelve degrees cooler for no throughput I could measure, while 200W falls off a cliff at −24%. Two cards still run there today. And I wrote down that those throughput numbers were sampled from a heterogeneous live job and cannot resolve a few percent — temperatures trustworthy, small deltas not. An earlier version of that method told me +29.5%, which is impossible, which is how I knew to distrust it.

03

How I work with Claude

Division of labour

I decide. It does the legwork.

Claude Code runs in my terminal with access to the repos and the box. It reads code, runs audits, writes scaffolding, builds containers and verifies its own work. What it does not do is choose. Every architectural call on both projects — mapper not cutter, one Whisper pass, no database — is mine, and several were made against the obvious suggestion.

Verification

Nothing counts until it runs.

The loop I insist on: make the change, run the tests, build the container, clone the repo clean into /tmp and run it from there. Both repos here were shipped that way — anything reaching outside the clone fails that test immediately, which is the only honest definition of "deployable".

Where it earns its keep

Catching what I'd have shipped.

Publishing these two repos started as a cleanup job. The audit found screenshots in the docs showing a real patient's generated note — embedded in two PDFs and sitting in git history. Then my personal email in the commit metadata, minutes before the repo went public.

Both were mine to fix, and I would not have found either by reading the diff.

Where I overrule it

It doesn't get to be confident for me.

The same day, it wanted to put a recall figure in my README that I remembered being higher. The artifacts backing it had been deleted months earlier, so the number went in at the lower value I could still verify.

A model will happily agree with your best memory. The repo only gets what the disk can prove.

04

Things I killed

  • A fine-tuned model A Malaysian Whisper fine-tune looked like the obvious fit for Manglish. Under translate it left Malay untranslated and couldn't emit Mandarin characters. Stock large-v3 won. The measurements are committed next to the config they rejected.
  • My own prompt work Weeks of prompt variants, swept across four videos, all statistically insignificant. The headroom was never in the prompt.
  • A better score A multimodal run beat my best recall — and contradicted itself several times more often. For an index, a confident lie is worse than a miss. Didn't ship it.
  • 630 GB of weights Models I'd collected and stopped using. If it lost a bake-off, it doesn't get disk.
  • A number I liked The README quotes 74.6% recall, not the higher figure I remembered, because the artifacts backing it were gone and I couldn't re-verify it.
