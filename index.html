MedicScribe

An AI scribe that writes the doctor's notes.

Problem

Malaysian doctors mix English, Malay, Chinese and Tamil in one sentence. Existing scribes expect English only and send patient audio to the cloud.

What I built

An Android app records the visit. A server on the clinic's own network turns it into a structured clinical note.

Who it's for

Clinics that want less typing without patient data leaving the building.

How I thought about it

Privacy is built into the code. Nothing is stored once the note is made, so the clinic doesn't have to trust a policy document.

Kotlin · Python · FastAPI · Whisper · local LLM

Podmetrix

Finds the moments in hours of recorded video.

Problem

Creators record for hours, edit days later, then scrub the whole file to find what happened.

What I built

A local tool that watches the footage and adds labelled markers to the editing timeline.

Who it's for

YouTubers and podcasters who edit long recordings.

How I thought about it

It labels every stretch, even the boring ones, instead of picking highlights. The editor decides what matters, not the AI.

kb

A knowledge base built for AI agents.

Problem

AI agents read whole documents to find one answer. That is slow and expensive.

What I built

A store that splits documents into sections, so an agent searches and reads only the part it needs.

Who it's for

Company knowledge that both people and AI assistants use.

How I thought about it

My first version did worse than plain files. I measured why, fixed the search, and tested again on new questions.

Rust · SQLite

ctxc

Lets AI safely change very large codebases.

Problem

An AI model can only read a small part of a big codebase at once, so it misses places a change affects.

What I built

A tool that finds every place a change touches, gives the AI only that code, then compiles and tests before saving.

Who it's for

Teams using smaller, cheaper AI models on real company-sized code.

How I thought about it

Before building, I tested three ways of finding code on public projects with millions of lines, and built on the one that missed nothing.

Python · language servers · Git

memfacts

Memory for AI assistants that doesn't make things up.

Problem

AI assistants forget between sessions, and the notes they write about past work can be wrong.

What I built

A memory that records only what actually happened (files, commands, requests), copied by code, not written by the AI.

Who it's for

Teams that rely on AI assistants and need a trustworthy record of what was done.

How I thought about it

I checked a sample of AI-written notes first. Enough were wrong that I took the AI out of the writing step.

llmw

My own private AI server.

Problem

Cloud AI charges per use and sends your data to someone else.

What I built

Software that turns a 4-GPU machine into an AI server any device on my network can use, with the GPUs set up automatically.

Who it's for

Running AI privately on personal or company data. Every project above runs on it.

How I thought about it

When something breaks, I find the cause before fixing it. One overheating GPU turned out to be airflow in its slot, not a bad card.
