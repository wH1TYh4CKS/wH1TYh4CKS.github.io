# wH1TYh4CKS.github.io

Personal site, served by GitHub Pages at <https://wH1TYh4CKS.github.io>.

One static `index.html`. No build step, no framework, no external requests —
fonts are a system stack, the favicon is an inline SVG data URI, and nothing is
fetched from a CDN. It loads on a cold cache in one round trip.

Edit `index.html`, push to `main`, done.
